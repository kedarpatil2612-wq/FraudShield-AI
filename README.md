
# 🛡️ FraudShield AI

### Intelligent Credit Card Fraud Detection System

🚀 **[LIVE DEMO — Try FraudShield AI]( https://fraudshieldkedar26.streamlit.app/ )**

A Machine Learning based application that detects potentially fraudulent credit card transactions using Logistic Regression.

## Features
- Interactive FinTech Dashboard
- Credit Card Fraud Detection
- CSV Batch Analysis
- Model Performance Analytics
- Dataset Explorer
- Interactive Visualizations

## Technology Stack
Python | Streamlit | Scikit-learn | Pandas | Plotly
